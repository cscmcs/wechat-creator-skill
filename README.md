面向现代 AI Agent（Antigravity / Cursor / Workbuddy / Claude / ChatGPT / Codex 等）深度定制的微信公众号全流程创作与排版技能（Skill）。

它能够：
- **格式零丢失排版**：把 Markdown / 纯文本快速编译为**样式 100% 内联、带 `<span leaf="">` 原子保护、粘贴到微信官方后台绝不掉格式**的合规富文本 HTML；
- **全流程端到端自然创作**：涵盖智能选题、事实核验、11 大经典文章结构、三阶去 AI 味润色、5 类高吸引力真实标题打磨；
- **专属文风画像学习与多版本管理**：分析作者 2~5 篇样文，智能提炼语气、句式与避坑词库，并通过 MCP 同步生成历史版本快照，创作时前置强制注入；
- **2.35:1 官方封面与配图规划**：遵循 900×383 官方比例与少字化设计原则；
- **一稿多发多平台分发**：无缝改写为 300~500 字小红书爆款图文卡片或带画面提示的 60 秒短视频口播脚本；
- **MCP 12 核心工具全自动化闭环**：创作完成自动入库平台工作台，支持直接推送到微信官方草稿箱。

## ✨ 核心能力概览

- **8+4 套精选微信原生内联主题**：包含科技前沿、深度商业、文艺特稿、干货教程、极简随笔，以及 4 套杂志级高定主题（松烟墨羽、手泽橄榄、金石黑金、霓灰极光），并支持用户在网页端保存专属自定义模板。
- **100% 原生内联 CSS · 彻底反过滤**：彻底杜绝 `<style>` 标签与外部 `class` 选择器。所有文本节点强制包裹 `<span leaf="">` 保护叶子节点，排版跨平台复制 100% 保真。
- **手机竖屏呼吸感节奏**：严格执行单段 1~3 句断行法则（手机端单段不超过 4~5 行），正文字号 15~16px，黄金行高 1.75~1.85，微字间距 0.5px，告别大段文字压迫感。
- **三阶去 AI 味责任编辑**：
  - *内容层*：拒绝泛泛而谈与机械平衡，强化核心观点与真实洞察；
  - *结构层*：拒绝“首先、其次、最后”的八股模版与假大空总结尾巴；
  - *语言层*：彻底剔除“底层逻辑、抓手、赋能、闭环、维度”等 AI 翻译腔与空洞大词。
- **专属文风学习与多版本快照**：
  - 支持分析 2~5 篇参考样文，提取包含 `tone`（核心语气）、`sentence_length`（句长习惯）、`paragraph_style`（段落节奏）、`avoid_patterns`（禁用套话词库）与 `preferred_patterns`（偏好词库）的风格档案；
  - 调用 `update_writer_profile` 存入平台，自动生成带时间戳的历史版本快照，支持网页端可视化微调与随时回滚；
  - 正文写作前强制调用 `get_writer_profile` 读取并作为最高约束注入指令。
- **11 大经典文章结构自然写作**：清单体、对比体、故事-反转-顿悟、问题-拆解-方案、特稿叙事、时间线复盘等，彻底防止同质化。
- **5 类高吸引力真实标题法**：打磨直接型、经验型、冲突型、结果型、故事型标题，杜绝耸动劣质标题党。
- **2.35:1 微信官方封面海报与配图规划**：严格遵循 900×383（2.35:1）官方推荐规格与少字化（<16字）排版。
- **多平台分发改写**：一稿多发，支持提取小红书爆款图文卡片与短视频带分镜口播脚本。
- **严谨事实查证与防幻觉**：溯源一手信源与数据时间戳，严禁模型臆造统计数字与案例。

## 🧭 四大核心工作模式

根据用户需求，技能可自动切换为以下四种模式：

### 模式 A：端到端全流程创作（推荐）
* **触发场景**：“帮我写一篇关于XXX的公众号推文”、“全流程创作推文并同步工作台”。
* **执行路径**：从阶段 0 智能选题到阶段 7 平台入库/草稿箱直推，全流程闭环执行。

### 模式 B：单环节专项作业
* **只查事实**：“帮我核实关于XXX的数据和一手信源” -> 执行 **阶段 1**；
* **只写初稿**：“根据这篇素材写一篇推文初稿” -> 执行 **阶段 2**；
* **只去 AI 味**：“帮我去一下这篇文章的AI味，语言改自然点” -> 执行 **阶段 3**；
* **只起标题**：“为这篇文章拟 5 个高点击率真实标题” -> 执行 **阶段 4**；
* **只排版**：“把这段 Markdown 编译为微信内联 HTML 排版” -> 执行 **阶段 5**；
* **只做封面**：“为推文设计 2.35:1 官方封面图方案” -> 执行 **阶段 6**；
* **直推工作台/草稿箱**：“把排好的文章推到工作台或微信草稿箱” -> 执行 **阶段 7**。

### 模式 C：专属文风分析与画像同步 (Style Analysis & Sync)
* **触发场景**：“分析我的风格”、“学习我的写作手法”、“保存我的写作风格”（提供 2~5 篇参考样文）。
* **执行路径**：
  1. 深度分析样文，提取核心语气、句长、段落节奏、避坑套话与偏好词汇；
  2. 组织为标准 JSON 格式，调用 MCP `update_writer_profile` 同步至平台；
  3. 平台自动生成新版本快照，后续创作时自动注入，用户亦可在网页端随时微调或回滚。

### 模式 D：多平台分发与改写 (Cross-platform)
* **触发场景**：“改写为小红书笔记”、“提取短视频口播脚本”、“一稿多发”。
* **执行路径**：
  1. **小红书图文版**：提取 3~5 个视觉卡片文案，强化封面主标题，搭配网感 Emoji 与互动问句，300~500 字；
  2. **短视频口播脚本**：按“黄金3秒抓手 -> 痛点共鸣 -> 核心干货 -> 引导互动”结构，输出含【画面提示】与预估时长的 60 秒脚本。

## ⚡ 8 阶段标准创作流水线

```text
[阶段 0: 智能选题与洞察] ──> [阶段 1: 事实查证防幻觉] ──> [阶段 2: 任务书确认与结构化写作] ──> [阶段 3: 三阶去AI味责任编辑]
                                                                                                      │
[阶段 7: 直推工作台/草稿箱] <── [阶段 6: 2.35:1封面设计] <── [阶段 5: 微信原生内联排版] <── [阶段 4: 5类真实标题打磨]
```

1. **阶段 0：智能选题与受众洞察**：分析受众核心痛点，定位文章传播价值。
2. **阶段 1：事实查证与一手信源核验 (`references/research.md`)**：核查数据时间戳与信源真实性；可调用 MCP `search_materials` 检索私有素材库。
3. **阶段 2：任务书确认与结构化自然写作 (`references/structures.md`)**：
   - **强制前置画像读取**：必须先调用 MCP `get_writer_profile` 获取作者文风；
   - **大纲停顿确认**：输出《文章任务书与大纲》，包含受众痛点、核心主张与章节逻辑，**停顿等待用户确认**；
   - 确认后再执行正文写作，严格执行 1~3 句断行呼吸感。
4. **阶段 3：内容/结构/语言三阶去 AI 味 (`references/humanizer.md`)**：内容层去空洞、结构层去八股、语言层彻底清除行业黑话与机械过渡词。
5. **阶段 4：5 类高吸引力真实标题 (`references/titles.md`)**：直接型、经验型、冲突型、结果型、故事型标题打磨。
6. **阶段 5：微信原生内联 CSS 排版 (`references/typesetting.md`)**：100% 编译为内联 `style` 且文字包裹 `<span leaf="">`；可调用 MCP `get_article_templates` 获取专属模板。
7. **阶段 6：2.35:1 官方封面海报设计 (`references/cover.md`)**：900×383 黄金比例与少字化（<16字）排版方案。
8. **阶段 7：平台工作台保存与官方草稿箱直推**：调用 MCP `save_article` 入库平台，或调用 `create_wechat_draft` 直推微信官方后台草稿箱。

## 🔌 MCP 平台深度集成与 12 大核心工具

本 Skill 原生支持 [Model Context Protocol (MCP)](https://modelcontextprotocol.io/)，与自建微信公众号创作平台及微信官方后台实现双向数据流闭环：

```text
                  ┌────────────────────────────────────────┐
                  │                AI Agent                │
                  │ (Antigravity / Cursor / Claude / etc.) │
                  └───────────────────┬────────────────────┘
                                      │  MCP JSON-RPC (SSE / Stdio)
                                      ▼
                  ┌────────────────────────────────────────┐
                  │            MCP Server 核心             │
                  │     (FastAPI + Database + Tools)       │
                  └──────┬──────────────────────────┬──────┘
                         │                          │
                         ▼                          ▼
      ┌───────────────────────────────┐   ┌───────────────────────────────┐
      │         平台网页工作台        │   │       微信公众平台官方后台    │
      │ • 可视化出版级排版定制器      │   │ • 官方草稿箱 (Draft Box)      │
      │ • 文风画像多版本微调/回滚     │   │ • 永久素材库 (图片/封面 CDN)  │
      │ • 个人素材库与文章管理        │   │ (严格仅存草稿，绝不自动群发) │
      └───────────────────────────────┘   └───────────────────────────────┘
```

### 核心 MCP 工具矩阵 (12 个工具)

| 工具名称 | 所属模块 | 触发阶段 | 功能说明 |
| :--- | :--- | :--- | :--- |
| `get_writer_profile` | 文风画像 | 阶段 2 前置 | **强制前置**：读取当前用户的专属写作风格画像（语气、句长、段落呼吸感、避坑套话、代表样文） |
| `update_writer_profile` | 文风画像 | 模式 C | **文风沉淀**：提取样文风格并持久化，在平台生成带时间戳的新版本快照，支持网页端回滚 |
| `search_materials` | 素材库 | 阶段 1 | 检索用户在平台上积累的私有事实素材、案例卡片与灵感备忘 |
| `save_material` | 素材库 | 阶段 1 | 向用户素材库中保存一条新事实数据、参考卡片或灵感笔记 |
| `get_article_templates` | 排版模板 | 阶段 5 | 获取系统预置的 12 套内联主题及用户在网页端保存的专属自定义排版模板 |
| `save_article` | 文章管理 | 阶段 7 | **核心交付**：保存文章并自动编译为 100% 内联 HTML；支持传入 `article_id` 执行覆盖更新 |
| `list_articles` | 文章管理 | 文章管理 | 分页/模糊搜索检索当前用户的历史文章列表 |
| `get_article` | 文章管理 | 文章管理 | 获取指定文章详情（含 Markdown 原文与编译后的微信内联 HTML） |
| `get_wechat_accounts` | 微信交互 | 阶段 7 | 获取当前用户绑定的公众号公开状态（安全脱敏，不暴露密钥） |
| `create_wechat_draft` | 微信交互 | 阶段 7 | **草稿直推**：将文章直推微信公众号官方草稿箱（仅存草稿，方便在微信后台终审） |
| `upload_wechat_cover` | 微信素材 | 阶段 6/7 | 上传本地封面图片至微信永久素材库，获取创建草稿必需的 `thumb_media_id` |
| `upload_wechat_image` | 微信素材 | 阶段 5/7 | 上传本地插图至微信官方图床，获取可直接嵌入文章 HTML 的微信 CDN 图片链接 |

## ❓ 常见问题 (FAQ)

### Q: 为什么复制到微信后台绝不掉格式？
**A**：微信后台编辑器会过滤 `<style>` 标签与外部 CSS 类名（`class`）。本技能所有排版产物**100% 将样式编译为内联 `style="..."`**，且文字节点全量包裹 `<span leaf="">` 原子保护标记，从而彻底免疫微信编辑器的清理与格式丢失。

### Q: 文风画像修改后如何回滚？
**A**：通过 MCP 的 `update_writer_profile` 提交新文风时，平台底层数据库会自动在版本历史表中新增一条快照记录。用户在网页端进入「写作风格画像」页面，即可查看所有历史版本并一键回滚到任意历史状态。

### Q: 草稿箱直推会有误发布的风险吗？
**A**：绝不会。`create_wechat_draft` 接口严格调用微信官方的 `draft/add` 草稿接口，仅仅是将内容存入微信后台的**草稿箱**中供作者预览，绝不触碰群发接口。
