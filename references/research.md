# 微信公众号事实调研与时效检索规约 (Research Rules)

> 本规范指导涉及技术、商业、产品、数据与时效性内容的事实核验，供 `wechat-creator` 技能按需引用。

---

## 一、 核心目标：真实可信的事实底座

一篇具有长期阅读价值的公众号文章，其竞争力很大程度上取决于事实的真实性、信源的权威度与数据的扎实佐证。

在撰写包含技术评测、商业动态、财报数据、政策法规或行业分析的内容前，必须进行信源核验，严禁依赖大模型知识库臆造时效性细节。

---

## 二、 信息来源分级标准 (Source Hierarchy)

引用事实与数据时，严格遵循以下信源分级，优先采用高层级信源：

### S 级：原始一手来源（最强佐证）
* 官方发布公告、官方开发文档、开源代码仓库提交记录；
* 法律法规条文、国家统计数据、公司经审计财报与招股书；
* 学术机构同行评议论文、官方接口规范与产品说明书。

### A 级：高质量一手报道（可靠事实）
* 权威媒体对当事人的直接采访问答与引语；
* 科技峰会、官方新品发布会的原始演讲记录与现场速记；
* 具备明确记者署名与交叉证据链的深度调查报道。

### B 级：可信二手来源（背景参考）
* 行业垂类主流媒体的评述与归纳总结；
* 独立第三方行业研究机构的公开研报；
* 知名行业专家的深度专栏分析。

### C 级：社区与用户讨论（感知线索）
* GitHub Issues / Discussions、Stack Overflow 技术讨论；
* Reddit、知乎、V2EX、X（Twitter）、小红书等社区的真实用户吐槽与体验反馈。
* **使用准则**：C 级信源可用于感知真实用户痛点、发现潜在缺陷与获取讨论线索，**严禁单独作为重大事实结论或财务数据的唯一依据**。

---

## 三、 结构化事实卡片规范 (Fact Card)

在整理核心事实与数据时，建议统一输出为标准化事实卡片：

```markdown
### 事实核验卡片 (Fact Card)
- **事实内容**：[简明扼要陈述客观事实或数据]
- **来源出处**：[具体机构名、文章标题或文档名称]
- **来源类型**：[S 级一手 / A 级报道 / B 级行业媒体 / C 级社区反馈]
- **发布日期**：[准确时间戳，如 YYYY-MM-DD]
- **访问时间**：[查证核对的时间]
- **可信程度**：[已交叉确认 / 官方单一声明 / 存在各方争议]
- **争议说明**：[是否存在质疑方或适用边界，如无则填“无”]
- **编辑备注**：[对正文引用的具体边界或使用建议]
```

---

## 四、 事实红线与反幻觉准则

1. **严禁捏造精确数字**：严禁无根据编写估值规模、融资额度、用户量增长倍数或测试跑分数据；
2. **严禁虚构引语与采访**：不得擅自为真实人物或高管编造未曾公开发表的讲话或私下聊天记录；
3. **严禁杜撰未发布的功能**：不得为真实产品赋予其尚未支持的特性或不兼容的环境；
4. **明确不确定性**：对于未经权威证实的技术传闻、内测爆料，正文中必须明确注明“据社区讨论显示”或“该特性目前处于未确认状态”，严禁作为既定事实直接断言。
