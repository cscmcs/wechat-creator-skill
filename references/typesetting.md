# 微信公众号排版技术规范与兼容性参考 (Typesetting Technical Reference)

> 本规范定义微信公众号富文本的技术约束与原生内联规则，供**用户明确要求直接输出原生 HTML 时**或调试排版引擎时按需引用。

---

## 一、 排版体系的架构分工

在 `wechat-creator` 体系中，文章生成与视觉排版严格解耦：

* **纯 Skill 基础流程**：LLM 专注高质量思考与文本表达，默认交付符合结构规范的 **Markdown 正文**与语义标记；
* **星河文场 MCP 增强流程**：由星河文场后端专业排版引擎（`core/typesetter.py`）依据主题样式表，将 Markdown 确定性编译为经过合规过滤的富文本 HTML，并持久化入库工作台。

> ⚠️ **按需读取原则**：撰写正文或普通对话时，**无需读取本文档**；仅在用户显式要求“直接输出微信 HTML 代码”时加载执行。

---

## 二、 微信公众平台编辑器的技术特性与约束

微信后台编辑器（mp.weixin.qq.com）对富文本有严格的安全过滤机制，实际表现可能随微信官方编辑器的版本更新而微调。为了达到高兼容度并尽量减少样式丢失，直接渲染 HTML 时须遵循以下约束：

### 1. 样式内联化要求
* 微信后台会直接剥离 `<style> ... </style>` 标签；
* 微信后台会过滤外部 CSS class 选择器（`class="..."`）；
* 必须将关键渲染样式直接内联到各元素的 `style="..."` 属性中；
* 避免使用外部 CSS 变量 `var(--...)`，色值应使用静态 Hex 或 RGB。

### 2. 标签兼容性建议
* **容器替代**：外层容器推荐使用 `<section>` 或 `<p>`，减少使用易被微信默认机制强制拆碎的裸 `<div>`；
* **文本叶子保护**：文字节点使用 `<span leaf="">正文</span>` 包裹，有助于微信富文本解析器将其识别为原子叶子节点，减少粘贴时行高、字间距与颜色被重置的概率；
* **严禁非法标签**：严禁包含 `<script>`、`<link>`、`<iframe>`、`on*=` 事件属性；
* **避免复杂定位与网格**：严禁 `position: fixed/absolute` 与 `display: grid`，并排元素建议使用简单的 `display: flex; align-items: center;`。

### 3. 标点与排版细节
* 正文标点统一使用中文全角标点，避免半角直引号与半角逗号混用；
* 代码块内严格保留等宽英文字符，避免移动端横向溢出。

## 三、 主题选择与平台联动机制

* **星河文场 MCP 环境**：
  * **严禁 Agent 凭空猜测主题 ID**；
  * 必须调用 MCP 工具 `get_article_templates()` 动态获取当前平台支持的主题清单（如系统精选主题与作者保存的私有自定义模板），并将所选主题名传入 `save_article(theme=...)`。
* **纯 Skill 独立环境**：
  * 无需也不应模拟平台主题 ID；
  * 可以向用户提供通用的视觉风格建议（如：极简纸实质感、沉稳冷灰调、柔和暖色手记、专业技术蓝等），指导正文配图与排版调性。
