# 作者痕迹检查（Author Trace Review）

> 用于初稿之后、Humanizer 之前，也用于编辑现有文章时先判断“作者是否在场”。目标是让真实材料和个人判断进入正文，不用第一人称、口语词或虚构细节假装有作者。

## 一、 先核对素材来源

按 **真实经历 > 具体事实 > 作者判断 > 概括性观点 > 修辞表达** 选择写作材料。优先保留用户已经提供的时间、数字、产品名、动作、失败经历、结果、原话；不要把它们压缩成“经历了许多挑战”“取得了不错效果”。

在内部为每个关键细节标明来源：作者亲述、作者原稿或笔记、可核验的公开资料、尚待确认。公开资料只能证明其实际支持的事实，不能证明作者亲历。作者画像或旧文可帮助识别表达习惯，不能自动成为新文章的经历、判断或引语。**严禁为了真实感虚构经历、数字、人物、场景和细节。**

## 二、 五项检查

检查的是是否有材料支撑，以及材料有没有真正进入正文；不是要求每篇文章都写成第一人称故事。

| 检查项 | 要问的问题 | 缺失时的处理 |
| :--- | :--- | :--- |
| 真实经历 | 作者给过亲历、观察、尝试、失败或取舍吗？稿中有没有保留？ | 有素材就回填；没有就不写“我经历过”。可以采用事实说明或评论体。 |
| 具体信息 | 已有时间、数字、产品、动作、结果、原话或限定条件是否清楚？ | 从原素材恢复准确细节；不把估计写成确定数字，不凭空补细节。 |
| 作者判断 | 作者明确表达了赞成、反对、疑虑、取舍或适用边界吗？ | 保留其判断与理由；没有就不代替作者下结论。 |
| 不可替代性 | 换一个作者，是否仍能原样写出这篇？有没有只有这位作者掌握的材料或视角？ | 找回已有经历、实际动作、观察或判断；仍无素材时缩小角度。 |
| 可署名性 | 去掉作者身份后，是否任何人都可以署名？ | 删去通用套话，改为有来源的事实；不能靠加“我”或伪口语解决。 |

## 三、 修订顺序

1. **先补已有素材**：找回被初稿省略的事实、过程、失败、结果及作者原话。保留时间先后、条件和不确定性。
2. **再调整叙述重心**：让一个真实动作、产品取舍或具体问题承担主线。若没有真实冲突或转折，就按平实过程推进。
3. **最后删减空泛内容**：删掉换产品名或作者名仍成立的段落，以及没有依据的第一人称感悟。不要用更漂亮的修辞替换同一段空话。

如果现有材料只能支持功能介绍、事实综述或教程，就如实写这种文章；不要伪装为个人故事。如果用户明确要求亲历口吻或所需篇幅超出材料，可问一两个能改变正文的问题（例如实际做了什么、哪里失败、最后结果如何），同时完成已可核验的部分。拿不到补充时标明边界，不编造、不靠抽象观点凑长。

## 四、 交接给 Humanizer

把已确认的事实、作者判断和表达习惯视为编辑边界。Humanizer 可以删空话、调节节奏和压缩重复，不能抹掉具体信息，也不能把作者略显笨拙但真实的表达统一抛光。最终编辑后再复核一次：稿件中的作者痕迹仍有来源，数字、时间、动作、结果和不确定性没有被改写。
